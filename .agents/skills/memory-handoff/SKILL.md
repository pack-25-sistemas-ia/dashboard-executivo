# Memória e passagem de bastão

- Atualize `MEMORY.md` a cada marco, só com fatos comprovados (comando + resultado): o que está VERIFIED, o que falta, riscos, decisões, armadilhas.
- Leia `MEMORY.md` e `AGENTS.md` antes de trabalhar; busque símbolos antes de abrir arquivos grandes.
- Não repita pesquisas já documentadas (OPEN_SOURCE_AUDIT).
